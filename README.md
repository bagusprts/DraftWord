# DraftWord

DraftWord is a cloud-based, high-performance text editor leveraging multi-threading and caching for real-time data analysis and optimization.

DraftWord is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftWord.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
